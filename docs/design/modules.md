# wayland: 模块与依赖方向

- **状态**: Frozen
- **冻结日期**: 2026-11-15
- **检查命令**: `scripts/check-dep.sh`, 退出码 0 即通过 (违规时打印 `from -> to`)
- **范围**: 本文件只列模块边界与依赖方向; 公共签名在 `docs/contracts.md`

## 模块清单

- **根包 `wayland`** -- `.` (模块根)
  - 职责: 提供连接入口, 运行时 (socket, 对象表, 分发, 往返), `wayland.xml` 的生成类型, 全部 interface 元数据, 公共错误与生成代码接缝.
  - 不负责: 具体扩展协议的 typed 绑定; 代码生成器; 示例程序.
  - 对外符号: `Connect`, `DialContext`, `DialFD`, `Display`, `Proxy`, `Arg`, `Interface`, `InterfaceByName`, `MustInterface`, 根包协议类型, 错误哨兵与 `ProtocolError`.

- **协议包 `protocols/<tier>/<name>`** -- `protocols/...`
  - 职责: 一个协议 XML 的生成 typed 绑定 (类型, 请求方法, handler 接口, 枚举).
  - 不负责: 运行时, 连接, 分发, 元数据表, 手写业务逻辑.
  - 对外符号: 该协议的生成类型, handler 接口, 枚举常量; 不含手写导出符号.

- **生成器 `cmd/waylandgen`** -- `cmd/waylandgen`
  - 职责: `go generate ./...` 的单个 main 包; 按 `parse.go`, `model.go`, `render.go` 文件完成读取, 校验, 生成与原子写入.
  - 不负责: 运行时, 协议包的手写逻辑, 示例.
  - 对外符号: 无公共 API; 不建子包.

- **示例 `examples/<name>`** -- `examples/...`
  - 职责: 5 个独立 main, 演示 registry, shm-surface, xdg-shell, input, output.
  - 不负责: 库行为, 生成器, 测试替身.
  - 对外符号: 无; 每个目录只放 `main` 包.

## 依赖方向 (白名单, 未列出即禁止)

| 允许的边 | 理由 |
| :--- | :--- |
| `wayland` -> 标准库 | 根包只依赖标准库 |
| `protocols/*` -> `wayland` | 生成包使用运行时与元数据 |
| `protocols/*` -> `protocols/*` | 仅生成器解析出的跨协议 interface 引用 |
| `cmd/waylandgen` -> 标准库 | 单个 main 包不依赖项目内其他包 |
| `examples/*` -> `wayland`, `protocols/*` | 示例使用库与协议绑定 |

**禁止**:

- `wayland` -> `protocols/*`, `cmd/*`, `examples/*`
- `protocols/*` -> `cmd/*`, `examples/*`
- `examples/*` -> `cmd/*`
- 任何包 -> `main` 或 `cmd/waylandgen` (生成器 main 除外)
- 生成包中出现手写 `.go` 文件

## 边界规则 (可机械检查)

- **R1**: 根包不 import 任何 `protocols/`, `cmd/`, `examples/` 路径.
- **R2**: 协议包只 import 根包, 标准库, 以及生成器解析出的其他协议包; 不得 import `cmd/` 或 `examples/`.
- **R3**: `cmd/waylandgen` 是单个 main 包, 只 import 标准库; 不建子包, 不 import 根包 / 协议包 / 示例.
- **R4**: 示例只 import 根包, 协议包与标准库; 不 import `cmd/`.
- **R5**: 包名按协议/领域命名; 禁止 `domain`, `service`, `repository`, `controller`, `utils`, `helpers`, `common`; 当前不建这些包.
- **R6**: `protocols/` 下每个 `.go` 文件必须以 `// Code generated by waylandgen; DO NOT EDIT.` 开头; 生成器是唯一写入者.
- **R7**: 跨协议 import 只由生成器写入; 重名 interface 按 stable 优先; 生成器无法解析时失败, 不生成 import.
- **R8**: tier 由 XML 父目录名决定; 只在输入存在时创建 tier / 协议目录; 生成文件名 `<dir>_gen.go` (`-` 换 `_`); 不同 tier 同名包用 import 路径区分.
- **R9**: `protocols/` 下不放 `_test.go`; 测试与夹具集中在根包或 cmd 的 `_test.go`; 不新建测试支持包.
- **R10**: 全部 interface 元数据只在根包生成; 协议包通过 `InterfaceByName` / `MustInterface` 取, 不生成各自的 meta 文件.

## 检查

`scripts/check-dep.sh` 用 `go list -f '{{.ImportPath}} {{join .Imports " "}}' ./...` 导出 import 边, 按上面的白名单判定; 违规打印 `from -> to` 并以非 0 退出. 同时检查 R5 的包名与 R6 的生成头.

当前仓库尚无 Go 包, L3 只能交付检查脚本; 真实 `go list` 输出在 L4 第一片补跑. 该限制写入 G3 证据.
