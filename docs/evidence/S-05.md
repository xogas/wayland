## Implementation notes

### Test-only raw bind

`bindUnknownRaw` creates a `Proxy` with a synthetic `Interface{Name, Version}` so the existing dynamic `wl_registry.bind` wire expansion in `encodeRequest` writes `name`, `interface`, `version`, and `new_id`. The proxy is then marked with the unexported `rawName`. `TestRawBindWire` reads the frame back over a socketpair and verifies all four fields:

```text
$ go test -count=1 -run TestRawBindWire -v .
=== RUN   TestRawBindWire
--- PASS: TestRawBindWire (0.00s)
PASS
ok  	github.com/xogas/wayland	0.003s
```

There is no exported API for unknown binds.

### Event skip by length

`readFrame` consumes the body according to the wire message size before dispatch. For a `rawName` object, dispatch skips the already-consumed body without decoding it, without opcode/signature checks, and without treating it as a protocol error. `skippedEvents` is the test-only counter used by RB02 to prove an event was skipped.

Unknown interfaces can also create server-owned child objects (`new_id` in an unknown event). The test-only raw-bind path enables `skipUnknownServer`, so events and `delete_id` messages for unregistered IDs in the server range `[0xFF000000, 0xFFFFFFFF]` are skipped by length. The marker is off for every public path. `TestRawSkipMarkerOffDoesNotWeakenUnknownObjects` proves an unregistered server-range event still returns E-07 and closes the connection when the marker is off.

### FD limitation

Without an interface signature the runtime cannot know how many descriptors an unknown event carries. The skip path does not guess: descriptors carried by a raw-object event or unknown-child event cannot be identified and are not closed individually. This is documented in the skip path comment. The tests avoid this limitation by only issuing registry binds; they never send a screencopy, dmabuf-export, gamma, or other request that would produce an fd event on an unknown object. No fd event was observed for the sway raw binds below.
