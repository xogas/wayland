### 当前会话的环境说明

当前 sway workspace 6 上有一个 fullscreen Chromium 窗口. 新映射的示例窗口会被它遮挡, sway tree 对示例窗口报告 `visible=false`, `rect=0x0`, 但 `geometry` 正确, 且客户端收到 `wl_surface.enter`, `wl_buffer.release` 和 activated configure. 这是 compositor 对 fullscreen 遮挡的呈现, 不是映射失败. X03 / X04 的最终 Esc 验证请切到一个空 workspace 后手动执行.


结论: 绑定 wl_seat, 打印 seat name 与 capabilities, 获取 keyboard 与 pointer, 映射窗口并等待输入. 原始 evdev keycode 与 wl_fixed 指针坐标需要真实输入; 当前窗口被 fullscreen 窗口遮挡, 且按任务要求不伪造 Esc, 因此 Esc 退出 0 与坐标打印记为手动待验证.

## 手动验证步骤

1. 切换到空 workspace, 例如 `swaymsg workspace 2`, 避免 fullscreen 窗口遮挡.
2. 运行 `go run ./examples/xdg-shell`, 确认 400x300 窗口与标题 `wayland-go demo`; 按 Esc 或关闭窗口; 期望退出 0.
3. 运行 `go run ./examples/input`, 确认 stdout 先打印 seat name 与 capabilities; 移动指针到窗口上, 确认出现 `pointer motion x=12.5 y=...` 一类 wl_fixed 十进制输出; 按 Esc, 确认出现 `key keycode=1 state=1` 且退出 0.
4. 可选: 运行 `go run ./examples/shm-surface`, 确认 200x200 纯色窗口约 1 秒后消失, 退出 0.
