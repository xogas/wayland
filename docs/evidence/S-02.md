布局检查项:

- 根包文件为 `protocol_gen.go` 与 `protocol_meta_gen.go`.
- 63 个协议目录各生成 `<dir>_gen.go`, 目录名中的 `-` 换成 `_`.
- 包名为目录名去掉 `-` / `_` 后的小写.
- 每个文件以 `// Code generated by waylandgen; DO NOT EDIT.` 开头, 且 gofmt 后与文件内容逐字节相同.
- `protocols/` 下没有手写 `.go`, 没有 `_test.go`, 没有多余生成文件.

## 元数据与接缝检查

`TestGeneratorMetadata` 逐项比较模型与 XML 源:

- protocol / interface / version / frozen.
- request / event 的 name, since, deprecated-since, destructor, opcode.
- arg 的 name, type, interface, enum, allow-null, 引用目标.
- enum 的 name, since, bitfield, entry name / value / since / deprecated-since.
- 13 个重名 interface 的 stable winner 与 loser 标记.
- 211 个 interface 全部出现在 `allInterfaces`; 198 个 wire name 出现在 `generatedInterfaces`.
- 每个 interface 的元数据变量唯一.

跨包接缝检查:

- 每个生成类型有 `Proxy()`.
- 有事件类型有 `New<T>(p, h)`, 无事件类型有 `New<T>(p)`, `Display` 有 `NewDisplay(p)`.
- `p` 字段未导出.
- 跨包对象参数生成 `x.Proxy().ID()`.
- 跨包 `new_id` 生成目标包 `New<T>`.
- 13 个 duplicate loser 不生成 `Bind<T>`; 其 new_id 目标使用包内局部 `wayland.Interface`.
- 重名包导入别名: `TestGeneratorImportAliasCollisions` 覆盖 `staging/foo-bar` 与 `unstable/foo_bar` 同为 `foobar` 包名时的 `unstablefoobar` 别名.
- `constructors/Proxy` 为导出符号.

## 运行时改动

- `Interface` 新增 `Frozen`, `Enums`.
- `Message` 新增 `DeprecatedSince`, `Destructor`.
- `ArgSpec` 新增 `Since`, `DeprecatedSince`.
- 新增 `Enum`, `EnumEntry`.
- 新增导出 `MustInterface`; `InterfaceByName` / `MustInterface` 使用 stable-preference 的 `generatedInterfaces`.
- `conn.sendRequest` 在 destructor 成功写入后设置 `stateDestroyPending`; 后续请求返回 `ErrObjectDestroyed`.
- 根包测试新增 `TestDestructorMarksDestroyPending`, `TestNonDestructorStaysAlive`, `TestInterfaceByNameStablePreference`.

## 已知偏差

- `ArgSpec.Since` / `ArgSpec.DeprecatedSince` 保留在类型中, 但当前 XML DTD 没有 arg 级 since 属性, 因此生成值恒为 0. 这是对契约字段的保守实现, 不伪造来源.
- `EnumEntry.Value` 使用 `int64`, 以同时容纳 spec 允许的 int32 与 uint32 范围; Go struct 无法表达联合类型. 当前 68 XML 的全部取值均在 int32 或 uint32 范围内.
- 类型名严格按契约 3.1 与 ADR-006 的前缀剥离规则: stable xdg-shell 生成 `Surface` / `Toplevel` / `Popup` 与 `SurfaceHandler` / `ToplevelHandler` / `PopupHandler`, 不采用契约 4.6 示例中的 `XdgSurface` / `XdgToplevel` 写法.
- 请求 enum 参数使用生成枚举类型 (契约 3.2 / 8.3), 例如 `ShmPool.CreateBuffer(..., format ShmFormat, ...)`. 契约 4.3 示例写 `format uint32`; 本实现以 3.2 / 8.3 的显式规则为准. 事件 enum 参数按 4.4 示例使用底层 `uint32` / `int32`.
- 参数名由 XML 名转 CamelCase, 并对 `id` 应用 Go initialism (`SetAppID`, `HardwareIDWacom`). 契约示例中的缩写 `sx` / `sy` 不保留, 生成名为 `surfaceX` / `surfaceY`.
- `go generate ./...` 的确定性用 65 个文件哈希证明; `git diff --exit-code` 为 1 是因为本切片按要求未提交, 不是生成抖动.
