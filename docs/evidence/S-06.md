## Exact refactor list

### 1. Test hooks

- Added unexported `conn.testHooks`, nil in production, with:
  - `rawNames map[uint32]string` for test-only raw-bound object names.
  - `skippedEvents map[uint32]uint32` for raw-object length-based event skips.
  - `skipUnknownServer bool` for the test-only broad unknown-child skip.
  - `unknownServerSkips int` for that skip counter.
  - `oobLen int` for the MSG_CTRUNC ancillary-size test.
- Added `conn.hooks *testHooks`; removed `conn.oobLen`, `conn.skipUnknownServer`, `conn.unknownServerSkips`.
- Removed `Proxy.rawName` and `Proxy.skippedEvents`.
- `display.go` and `conn.oobSize` consult `c.hooks` only when it is non-nil.
- `object.deleteID` consults `c.hooks` for the test-only broad skip.
- Production behavior is unchanged: with `hooks == nil`, unknown objects still close the connection and return E-07; `TestRawSkipMarkerOffDoesNotWeakenUnknownObjects` still passes.
- The raw bind stays unexported test code (`bindUnknownRaw`); no public API was added.

### 2. File split

- `conn.go`: `conn` struct, `testHooks`, `Connect` / `DialContext` / `DialFD` / `resolveSource` / `newDisplay`, `beginDispatch`, `isClosed`, `close`, `closeFDs`, `sendRequest`, `write`, `ensure`, `oobSize`, `readMore`, `readFrame`, `unreadFrame`, `takeFD`.
- `object.go`: object table, `lookup`, `newObject`, `newIncomingObject`, `allocIDLocked`, `release`, `deleteID`, `markTombstone`, `markDestroyPending`.
- `wire.go`: `encodeRequest`, `decodeArgs`, dynamic `wl_registry.bind` expansion (`dynamicNewIDTarget`), `appendU32`, `appendStringField`, `pad4`, `align4`, `validFD`, `closeArgFDs`, `closeOOBFds`.
- Remains `package wayland`; no new package, no import cycle.

### 3. Error chain

Replaced every `fmt.Errorf("... %w: %v", sentinel, cause)` with two `%w` verbs, preserving the sentinel and the underlying cause for `errors.Is` / `errors.As`:

- `DialContext`: `ErrConnect` + dial cause.
- `DialFD`: `ErrConnect` + `net.FileConn` cause.
- `conn.write`: `ErrIO` + write cause.
- `conn.readMore`: `ErrIO` + read cause; `ErrMalformedMessage` + control-message and fd-parse causes.
- `Display.dispatchOne` sink error: `ErrProtocolViolation` + sink error.
- `cmd/waylandgen/parse.go`: `err == io.EOF` changed to `errors.Is(err, io.EOF)`.

Error message text is unchanged because `%w` and `%v` format the same operand. Added `TestErrorChain` covering `DialContext` (`ErrConnect` + `fs.ErrNotExist`), read (`ErrIO` + `io.EOF`), write (`ErrIO` + `EPIPE`), and sink delivery (`ErrProtocolViolation` + sink sentinel).
